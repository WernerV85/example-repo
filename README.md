# **Inventory module for shoe shop**
## M03T07 - OOP - Synthesis
### Stock capturing, displaying and calculating cost


The script was developed for the use in shoe retail.

Initialising the programme creates a menu with different option for the user to select

<img width="324" height="213" alt="image" src="https://github.com/user-attachments/assets/82c05295-f2dd-4b86-9ef0-6dc93f108dd2" />

The user is able to view stock from all the locations and shops

As well as calulate the Inventory cost for each of the shoe they stock.
The user can search, both on name and stock code.
Other calculations include Extracting the shoe with the most stock, indentifying sale items.

It also allows the user to add new inventory (shoe) to the list, taking into account the location, name, price and stock value of the item.
It also allows for adding stock, by calculation the stock item with the lowest value.
